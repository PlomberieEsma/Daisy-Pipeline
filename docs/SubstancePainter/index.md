# Substance Painter Plugin

## Général
Ceci est la documentation du plugin Adobe Substance 3D Painter pour Prism.

Ce plugin permet aux utilisateurs de simplifier les imports de fichiers de géométrie dans Substance Painter, d'enregistrer et de versionner leurs scènes de travail ainsi que d'exporter leurs textures vers un projet Prism.

Cette documentation est destinée à des utilisateurs maîtrisant déjà l'utilisation de base du logiciel Adobe Substance 3D Painter. Voici la [documentation officielle](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/home) de ce logiciel si nécessaire.
