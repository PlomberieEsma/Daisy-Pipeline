# DaVinci Resolve Plugin
[< Page précédente](README.md)
## Général
Ceci est la documentation du plugin DaVinci Resolve pour Prism.

Ce plugin permet aux utilisateurs de simplifier les imports de shots depuis le pipe, d'automatiser leur mise à niveau si une version plus récente existe, de simplifier le travail en réseaux du montage sur différents appareils et d'uniformiser la localisation et la naming des exports.

Ce plugin comporte 2 presets pour le format **SCOPE (2048 x 858)** et **FLAT (1998 x 1080)**

Cette documentation est destinée à des utilisateurs maîtrisant déjà l'utilisation de base du logiciel Adobe Substance 3D Painter. Voici la [documentation officielle](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/home) de ce logiciel si nécessaire.
